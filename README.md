# URL Shortener - Spring Boot

A production-grade URL Shortener REST API built with Spring Boot, PostgreSQL, and Spring Data JPA.
Converted from an original Go/Gin implementation.

## Tech Stack
- Java 21
- Spring Boot 4.0.6
- Spring Data JPA + Hibernate
- PostgreSQL
- Lombok
- SpringDoc OpenAPI (Swagger UI)

## Features
- Shorten any URL to a 6-character code
- Custom short codes
- Click tracking
- URL expiry support
- Input validation
- Swagger UI documentation
